## Bug Reports

If something is broken, open an Issue in the relevant repository:
- FHIR API / CapabilityStatement / resource validation → [zs-fhir-server](https://github.com/zarishsphere/zs-fhir-server/issues)
- FHIR search, terminology, subscriptions, bulk data → the specific `zs-fhir-*` repository
- SMART on FHIR / auth token issues → [zs-fhir-gateway](https://github.com/zarishsphere/zs-fhir-gateway/issues)
- REST API / core backend issues → [zs-core](https://github.com/zarishsphere/zs-core/issues)
- Frontend / browser issues → the specific `zs-esm-*` repository
- Deployment issues → [zs-infra-docker](https://github.com/zarishsphere/zs-infra-docker/issues)
- Form builder issues → [zs-esm-form-builder](https://github.com/zarishsphere/zs-esm-form-builder/issues)

Use the bug report template — it asks for exactly what I need to reproduce the issue.

## Email Support

**Platform and technical questions:** platform@zarishsphere.com
**Clinical and health system questions:** health@zarishsphere.com
**Donor and partnership questions:** donors@zarishsphere.com
**Security vulnerabilities:** platform@zarishsphere.com (see SECURITY.md)

Response time: I aim to respond within 5 business days. For urgent clinical system failures, mark your subject line with `[URGENT]`.

---

## What I Cannot Support Here

- Commercial support contracts (ZarishSphere is free and open source)
- Customizations specific to your organization's internal systems
- Real-time support (I respond asynchronously)

For commercial deployment support, I recommend engaging an OpenMRS or DHIS2 certified implementer.

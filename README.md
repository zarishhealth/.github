This public repository provides ZarishHealth's organization profile,
community-health files, issue forms, and shared brand kit.

- Organization profile: [`profile/README.md`](profile/README.md)
- Community guidelines: [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)

- Security policy: [`SECURITY.md`](SECURITY.md)
- Brand kit: [`profile/assets/BRANDING.md`](profile/assets/BRANDING.md)

## No workflow automation

This repository intentionally contains no GitHub Actions workflows, reusable
workflows, or workflow templates. Commits and pull requests here will not start
Actions jobs. There are no scheduled jobs or automated dependency update jobs.
Other repositories in the organization are unaffected.

GitHub organization and repository settings—such as who can write, branch
protection, review requirements, and Actions permissions—are controlled in
GitHub settings. They are not changed by files in this repository.

Please never include credentials, patient information, identifiable site
details, or unredacted production logs in public issues or pull requests. Use
synthetic examples only.

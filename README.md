# ZarishHealth organization repository

This repository contains the ZarishHealth GitHub organization profile, community-health files, reusable governance workflows, and shared brand kit.

- Organization blueprint: [`BLUEPRINT.md`](BLUEPRINT.md)
- Organization profile: [`profile/README.md`](profile/README.md)
- Brand guidelines: [`profile/assets/BRANDING.md`](profile/assets/BRANDING.md)
- Security policy: [`SECURITY.md`](SECURITY.md)
- Public security metadata: [`/.well-known/security.txt`](.well-known/security.txt)

The brand mirror workflow requires an organization secret named `PAGES_REPO_TOKEN` with the minimum permissions needed to update `zarishhealth/zarishhealth.github.io`. No credentials or patient data belong in this repository.

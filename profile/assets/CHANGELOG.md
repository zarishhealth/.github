# Changelog

## 1.0.0 — 2026-09-19

Initial release of the ZarishHealth brand kit.

### Added
- Vector master mark: shield + stethoscope "Z" + cross, with the cross gap drawn as
  split geometry (no SVG masks) so it renders identically in every engine.
- Simplified small-size mark for rendering below 32 px.
- 6 logo colour variants across horizontal, stacked and wordmark-only forms,
  plus 3 pre-baked background plates.
- Full favicon set: multi-size `.ico`, dark-mode-adaptive SVG, PNG 16→512,
  Safari pinned-tab SVG.
- App icons for iOS, iPadOS, Android (incl. maskable adaptive), PWA, macOS,
  Windows tiles, watchOS and tvOS.
- Avatars for GitHub, X/Instagram/Mastodon, Slack, Discord, npm, Docker, Gravatar.
- Social cards at Open Graph, X, GitHub, LinkedIn, Facebook, Slack and WhatsApp specs.
- 13 banners: README, docs, X, LinkedIn (company + personal), Facebook, YouTube,
  email, slide title, app splash.
- 11 README badges in SVG and 3× PNG.
- Network-pattern backgrounds and a print watermark.
- Design tokens: `brand-tokens.json`, `brand.css` (light + dark).
- Web config: `site.webmanifest`, `browserconfig.xml`, `head-snippet.html`.
- Reference sheets: palette, typography, clear space, overview.
- `BRANDING.md` guidelines and `SKILL.md` machine-readable brand spec.

### Known placeholders

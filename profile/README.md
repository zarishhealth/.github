# ZarishHealth

**Ultra-Portable, Self-Hosted, Offline-First Health Information System (HIS)**

[![Website](https://img.shields.io/badge/website-zarishhealth-0F9D8C?style=for-the-badge)](https://zarishhealth.github.io/)


</div>




ZarishHealth is a complete, multi-platform, vendor-independent Health Information System built for low-resource environments, non-profit field operations, and clinical facilities. It operates completely offline on local devices and synchronizes seamlessly across local Wi-Fi networks without requiring external cloud infrastructure or proprietary vendors.
